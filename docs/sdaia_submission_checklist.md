# قائمة التحقق لتسليم مشروع FI'L AI إلى SDAIA

## متطلبات مكتملة وقابلة لإعادة التشغيل

- [x] خط NLP متكامل محلي: تطبيع، تصنيف، استخراج، تفسير سياقي، مراجعة، وتخزين.
- [x] نموذج أساسي TF-IDF + Logistic Regression محفوظ وقابل للتشغيل.
- [x] CAMeLBERT-DA مضبوط دقيقًا ومحمل من `models/FIL_AI_CAMeLBERT/` دون استبدال صامت.
- [x] تمثيل embeddings فعلي باستخدام `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` وقرار ربط محافظ.
- [x] مقارنة النموذج الكلاسيكي وCAMeLBERT على نفس تقسيم Colab الاصطناعي ذي 125 رسالة، مع حفظ حدود المصدر.
- [x] تقييم كمي وتحليل أكثر من عشرة أخطاء من artifacts محفوظة.
- [x] واجهة React وFastAPI وSQLite/PostgreSQL، مع بقاء Gradio كعرض احتياطي.
- [x] تقويم ميلادي، سجل مواعيد قديمة/حالية، إنشاء يدوي، واستيراد CSV/XLSX بعد المعاينة.
- [x] اختبارات Python وReact وبناء production وأوامر تشغيل موثقة.

## قيود يجب ذكرها في العرض ولا يجوز إخفاؤها

- [ ] لا توجد حتى الآن مجموعة اختبار واقعية داخل المجال ومراجعة بشريًا؛ العدد الحالي صفر.
- [ ] ملف الصفوف الـ500 وتقسيم عائلات إعادة الصياغة غير موجودين محليًا، لذلك لا يمكن تدقيق تسرب paraphrase-family.
- [ ] تنبؤات صفوف اختبار Colab ومصفوفة التباسه غير محفوظة؛ المتاح هو المقاييس الإجمالية المبلّغ عنها.
- [ ] نتيجة CAMeLBERT البالغة 95.8% على 24 رسالة ملوثة بالتداخل مع بيانات الضبط، وليست دليل تعميم.
- [x] المقارنة الأساسية معروضة بوصفها نتائج Colab مُبلّغًا عنها على 125 اصطناعية: 72.0% مقابل 89.6% (+17.6 نقطة مئوية)، وليست دقة واقعية أو إعادة إنتاج محلية.
- [ ] تقييم المطابقة الدلالية صغير جدًا: 4 تحقق و8 اختبار اصطناعية؛ لا يكفي لاعتماد عتبة مستقرة.
- [ ] لا توجد مصادقة مستخدمين أو صلاحيات مؤسسية؛ التطبيق نموذج capstone محلي.

## حالة مستودع GitHub

1. المستودع العام: `https://github.com/rahk2003/fil-ai-arabic-action-intelligence`، والفرع الافتراضي `main`.
2. checkpoint الخاص بـCAMeLBERT محفوظ باستخدام Git LFS؛ يلزم `git lfs pull` بعد الاستنساخ.
3. `.env` وقاعدة SQLite والرسائل التشغيلية الخاصة والبيئات الافتراضية و`node_modules` ومخبأ embeddings مستبعدة.
4. تم تشغيل اختبارات Python وReact وproduction build والاستدلال المحلي قبل التسليم.
5. يجب تجربة تشغيل نظيفة من README وفتح `/api/health` والواجهة على جهاز العرض النهائي.
6. يجب الإبقاء على إسناد MASSIVE وCAMeLBERT وMiniLM، وعدم تفسير النتائج الاصطناعية كدقة واقعية.
